Architectural Pillars

Engineered for Precision & Learning

Built according to strict production criteria with the official MongoDB driver, highlighting pure query optimization, aggregation mechanics, and clean code principles.

Native Driver Power

Uses the official MongoDB Node.js driver rather than Mongoose. Experience direct driver commands like insertOne(), find().toArray(), and raw $set pipelines.

Intra-Document Progress

Features pagesRead comparison via MongoDB $expr. Power dynamic filters like /api/books/unfinished to evaluate field-against-field values on the fly.

Multi-Stage Aggregation

Extract deep library metrics across categories, reading statuses, average ratings, and pace using $match, $group, and controller-level data reshaping.

Data Integrity & Quality

Equipped with intentional consistency checks (such as /api/books/inconsistent) and enum guards for clean categorization and dependable persistence.

Schema Definition

The Book Collection Model

A single collection named books inside the personal_library database, engineered with clear field validation constraints.

Field Specifications

Collection: books
Field Type Status Constraints & Rules
title String Required Trimmed, 1 – 150 characters
author String Required Trimmed, 1 – 100 characters
category String Required programming, software-engineering, business, history, science
pages Integer Required Range 1 – 5,000
pagesRead Integer Optional Default 0, range between 0 and pages
rating Number Optional Default 0 (unrated), 0–5 in steps of 0.5
status String Optional reading, completed, or planned (default)
publishedYear Integer Required 1000 up to current year
tags Array Optional Array of strings, max 5 items, lowercase
addedAt Date System Auto-assigned new Date() by server

Developer Workflow

Get Started in 4 Easy Steps

Spin up the server, connect your local MongoDB instance, and seed test books in under two minutes.

1

Install Dependencies

Installs Express 5, MongoDB native driver, Helmet, and development utilities.

npm install
2

Configure Environment

Copy .example.env to .env and specify your MongoDB connection URI and PORT.

cp .example.env .env
3

Launch with Nodemon

Start the development server with live reload and automatic environment injection.

npm start
4

Verify System Health

Hit the health endpoint to confirm server and MongoDB connection status.

curl http://localhost:4000/api/health
